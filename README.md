# Rent Hives

A simple responsive fashion rental landing page built with HTML, CSS, Bootstrap, and Font Awesome.

## Overview

This project showcases a fashion rental storefront called **Rent Hives**. The main page includes:

- Hero section with navigation and search controls
- Featured collections for bridal, men, and party wear
- Responsive product cards and image carousel
- Custom styled layout using Bootstrap + custom CSS

## Files

- `index.html` — Homepage layout and content
- `index2.html` — Secondary page for category listings or product sections
- `index3.html` — Account/profile page placeholder
- `css/bootstrap.min.css` — Bootstrap framework styles
- `css/style.css` — Custom project styling
- `css/style2.css`, `css/style3.css` — Additional style variations
- `js/bootstrap.bundle.min.js` — Bootstrap JavaScript bundle
- `js/script.js`, `js/script2.js`, `js/script3.js` — Project scripts
- `images/` — Project images and brand assets

## How to view

1. Open `index.html` in a web browser.
2. Alternatively, host the project folder using a simple local server (e.g. Live Server extension).

## Notes

- The project is built for frontend presentation only.
- Use the included `images/` assets for the full visual experience.
